# Skill icon sources

Every stack row image under `assets/skills/rows/` is generated by
`scripts/build-skill-tiles.mjs` from two sources.

- Glyph files in `assets/skills/icons/` are copied unchanged from the `icons/`
  folder of https://github.com/tandpfun/skill-icons at commit
  `7f7e691e71aec64e8354bf697835e009d1ad80f8`. That project is MIT licensed
  (https://github.com/tandpfun/skill-icons/blob/main/LICENSE).
- The custom tiles it draws for Keras, Hugging Face, Jupyter, Kaggle, Ollama,
  Gradio, Streamlit and Neo4j use paths from the `simple-icons` npm package
  pinned in `package.json`. Simple Icons is licensed CC0 1.0
  (https://creativecommons.org/publicdomain/zero/1.0/).
